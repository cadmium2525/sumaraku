# ラクガキ大乱闘

描いたラクガキが3Dのキャラクターになって戦う、スマホ向けの対戦アクションゲームです。
three.js で動き、GitHub Pages にそのまま置けます（ビルド不要）。

## あそびかた

1. **ラクガキする**：全身のガイドを見ながら「頭 → 体 → 腕 → 足 → その他」の順に描きます。
   - 閉じた形（丸・四角など）は自動でぬりつぶされ、ふっくらした立体になります（「ぬり」で切り替え）。
   - 線は 3D ペンで描いたようなチューブになります。顔など、ぬった形の内側に描いた線は表面に出ます。
   - 「その他」は武器・帽子・しっぽなど自由に。武器キャラになると手に持ちます。射撃型だと弾になります。
2. **キャラ化**：タイプがランダムで決まり、タイプに合わせてワザが決まります（同じラクガキはいつも同じワザ）。
   - 軽量近接格闘型：速くて軽い。連続ワザが得意
   - 重量破壊型：重くて一撃が重い。スーパーアーマー付きのワザあり
   - 射撃型：チャージショット・ミサイル・ボム・地雷など飛び道具
   - 武器キャラ：描いた武器でリーチの長い斬撃。武器が長いほどリーチも長い
3. **自分で戦う（CPU戦）**：1on1・ストック3・アイテムなし。CPU のつよさは 1〜9。
4. **オートバトル（レート戦）**：ほかの人のラクガキと自動で対戦。勝敗でレート（イロレーティング）が変わり、ランキングに反映されます。

### 操作（スマホ）

| 操作 | 内容 |
|---|---|
| 左側をドラッグ | スティック（どこを触ってもそこが中心になります） |
| スティックをはじく | スマッシュ入力（スマッシュ攻撃・ダッシュ・回避・すり抜け床から降りる・急降下） |
| 攻撃 | 弱攻撃・強攻撃・スマッシュ攻撃（長押しでため）・空中攻撃 |
| 必殺 | 方向＋必殺ワザ（通常・横・上・下） |
| ジャンプ | 長押しで大ジャンプ、短く押すと小ジャンプ。空中でもう1回 |
| ガード | 押しっぱなしでシールド。ガード＋攻撃＝つかみ、ガード＋はじき＝回避、空中では空中回避 |

キーボードでも遊べます：矢印/WASD＝移動（Shift で弱入力）、J＝攻撃、K＝必殺、スペース＝ジャンプ、L＝ガード。

## GitHub Pages で公開する

1. このリポジトリを GitHub に push します。
2. GitHub のリポジトリ → **Settings → Pages** → 「Build and deployment」の Source を **Deploy from a branch** にし、
   公開したいブランチ（例：`main`）と `/ (root)` を選んで保存します。
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で遊べます。

ビルドは不要です。three.js は `lib/` に同梱しています（three r170, MIT License）。

## Firebase の設定（ランキング・ラクガキの共有）

Firebase を設定するまでは **オフライン**（この端末の中だけ。サンプルキャラが対戦相手）で動きます。
設定すると、みんなのラクガキと対戦でき、ランキングも共有されます。

1. [Firebase コンソール](https://console.firebase.google.com/) でプロジェクトを作成します。
2. **Authentication** → 「始める」→ ログイン方法で **匿名** を有効にします。
3. **Firestore Database** → 「データベースの作成」（本番環境モード、リージョンは `asia-northeast1` など）。
4. Firestore の **ルール** タブに、このリポジトリの `firestore.rules` の中身を貼り付けて公開します。
5. **プロジェクトの設定 → マイアプリ** で「ウェブ」アプリを追加し、表示された `firebaseConfig` の値を
   `js/data/firebase-config.js` に貼り付けます。
6. **Authentication → 設定 → 承認済みドメイン** に `<ユーザー名>.github.io` を追加します。

タイトル画面の右下が「オンライン」になれば接続できています。

### 保存されるデータ

- `characters/{id}`：キャラ名・タイプ・ワザのシード・ラクガキ（JSON 文字列）・作者・レート・勝敗・通報数
- `characters/{id}/reports/{uid}`：通報（1人1回）。3件で非表示になります

### 注意

- レートの更新はクライアントから行っています。ルールで「1回の変動は ±40 まで」「対戦数は +1 ずつ」に制限していますが、
  完全な不正対策ではありません。本格的に運用する場合は Cloud Functions で対戦結果を検証する形にしてください。
- 1人が作れるキャラは 5 体までです（`js/data/store.js` の `MAX_CHARS`）。

## 開発

```sh
npm run serve   # http://localhost:8080 で起動（python3 の簡易サーバー）
npm test        # AI どうしの対戦をヘッドレスで回して、試合が成立するか確認
```

URL に `?debug` をつけると攻撃判定（赤）・やられ判定（黄）が表示されます。

### ファイル構成

```
index.html
css/style.css
lib/                      three.js（同梱）
js/main.js                画面の切り替えとゲームの流れ
js/ui/draw.js             ラクガキ画面
js/ui/preview.js          キャラの 3D プレビュー
js/ui/sound.js            効果音（WebAudio で合成）
js/doodle/model.js        ラクガキのデータと骨格（肩・股・首・武器の握り）の計算
js/doodle/builder3d.js    ラクガキ → 3D モデル
js/doodle/samples.js      サンプルキャラ
js/game/constants.js      ステージ・ふっとばしの定数
js/game/archetypes.js     タイプごとの性能とワザ
js/game/fighter.js        ファイターの状態遷移と物理
js/game/sim.js            ヒット判定・ふっとばし・飛び道具・撃墜
js/game/ai.js             CPU
js/game/anim.js           ポーズ（アニメーション）
js/game/render.js         three.js の描画・エフェクト・カメラ
js/game/input.js          タッチ操作・キーボード
js/game/match.js          試合の進行と HUD
js/data/store.js          保存（localStorage / Firestore）
js/data/rating.js         イロレーティング
js/data/firebase-config.js
firestore.rules
tests/sim.test.js
```

ゲームの中身（`js/game/` の sim / fighter / ai / archetypes）は描画と分かれていて、乱数も固定シードなので、
オートバトルの「スキップ」は同じ計算を一気に進めるだけです。
